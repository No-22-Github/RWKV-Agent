## 0. 结论

1. **v1.3 state 在 workbank 上大幅、稳定提分**：干净 112 题 none 4.0 → v13b-s688 24.7 / v13b-fin 27.7（三次均值），
   按题配对 +39/−6、+43/−5（p < 1e-6）。高于 v1.2 最佳 m432（20/112，temp-3601 基模）。
2. **bfcl-product 仍然下降**：none 39.7 → s688 30.0（p = 0.085）/ fin 25.3（p = 0.003），主要掉在中文 40 题（29 → 21 / 18）。
   所有 state 点都掉，与学习率（lr2e-2 / lr1e-2）、训练长短（2 epoch / 2.7 / 3）无关，是数据问题。
3. **选点：推荐 `v13b-s688`**（lr1e-2，第 688 步）。它与 v13b-fin 在两个套件上都分不出（workbank p = 0.73、bfcl p = 0.39），
   但对 none 的 bfcl 损失不显著（p = 0.085），fin 的显著（p = 0.003）。
4. 两个学习率之间分不出（终点 workbank +10/−7，p = 0.31）；workbank 随训练持续上涨（s516 → fin 约 +10）。

## 5. bfcl 掉分原因（none 对、v13b-fin k0 错的 28 题）

1. 不听「不要调用工具」/ 不需要工具的题也调（12 题，missing-required 与 multiturn 的「根据上一轮证据重复这个值」）。
2. 调用本轮未提供的工具：`web_search` 6 次——背熟 workbank 固定目录，41% 目录轮换没压住。
3. 收尾阶段仍吐工具调用（9 次）。
4. 反问措辞没用判据关键词（「哪个文件或目录」而非「路径」）。

v1.4 补数方向：遵守用户的「不要调用工具」、只调本轮提供的工具、多轮沿用上一轮证据直接作答、中文反问用「路径/关键词」类明确措辞。
