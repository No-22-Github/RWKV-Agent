## 0. 结论

1. **最优 checkpoint：`v12m-s432`（mixed 路 step 432，3.0/4 epoch）**。
   workbank 干净 112 题 **20/112**（主指标）——对 `none`（9/112）**+11**（配对翻转 +13/−2，单侧 p=0.0037，
   bootstrap 95% CI [3.6pp, 16.7pp] **不含 0**）；对 `t927`（6/112）**+14**（+17/−3，p=0.0013，CI [3.5pp, 22.2pp] 不含 0）。
   148 全量 23/148 与 bfcl-product 27/60（与 v12m-s288 并列 state 最高）同为全场第一。
   按预注册规则：对第二名 v12m-s384（15）差 5 > 2，不需 bfcl 平局规则；对 none / t927 差均 > 2，
   可宣称提升；对 t927 单侧 p ≤ 0.05，**M4 补副本不触发**。
2. **`✿` 续写修复完全生效**：v1.1 语料的 t927-s316 今天仍有 3（workbank）+6（bfcl）题终答复写
   `✿textN✿User:`；**12 个 v1.2 state arm 两套件全部 0 题**。每条终答后接 `\n\nUser:` 的语料改动
   把"答案之后不停止"的形态清零——这是本轮比分数更重要的结论。
3. **mixed 路整体强于 suffix-only 路（只陈述，不归因 lr）**：mixed 同时改了数据与 lr（1.5e-2），
   两变量混在一起。mixed 峰值 20/112 高于 suffix-only 峰值 13/112（s158、s395 并列）；
   全部 8 个 mixed 点里 4 个 ≥ 11，suffix-only 6 点里 4 个挤在 12–13、峰值不突出。
   两路曲线都锯齿形，但 mixed 在 3.0/4 epoch 处出孤立高点。
4. **s432 的弃权保留是全场最好**：workbank notool 类 **9/12**（超过基模 none 的 7/12，
   t927 只有 2/12），bfcl irrelevance **18/20**（基模 11/20）。m288（irrelevance 20/20 但 notool
   仅 5/12）与 m576（16/20、2/12）也部分保留"不该调就不调"，但只有 s432 连 notool 一起保住。
   "该调才调"和"调完会做"第一次同时成立，代价是它两侧邻点（s384 15、s480 8）没有继承这一形态，
   checkpoint 选择对结果极其敏感。
5. **none 与 t927 的干净 112 题基线（t927 报告 §8 承诺的数字）：none 9/112，t927-s316 6/112**。
   t927 在干净口径下**低于**基模 3 题（+5/−8）——t927 报告里 148 全量的 +7 优势按干净口径重测后消失，
   证实了那份报告"含泄漏"的担忧。

- 比较两路只能到"mixed 的最高点更高"，**不能说 lr 1.5e-2 更好**（数据同时变了）。

## 7. 失分分层（`run gate`，capability 层才算"模型不会"）

- 32 个 run 中被判"可以当能力读数"的有 4 个：**v12m-s288 的两个套件、v12m-s432 与 v12m-s576 的
  bfcl run**（protocol 层 ≤ 1.7%）；其余 run 的 workbank 失败仍以 protocol 层为主（31–58%）。
- workbank 上 protocol 失败最少的 state 是 **m288（2 个）、m576（15 个）、m432（16 个）**，
  对比其余 state 的 47–86 个——协议稳定性与干净分数在 mixed 后段同步变好，
  其中 m432 兼有最高 capability 通过数（23）。
- 契约拒绝题数（终答以拒绝语开头）：none 43 题最多（基模大量直答违契约）；t927 30；
  v1.2 各 state 6–22，整体下降，与 `✿` 清零同向，说明终答格式纪律整体改善。

## 8. 局限

- **k=1 单副本**：除 m432 外所有 arm 的 CI 都跨 0；m432 的显著性建立在一次采样上，
  如需硬结论可对 m432 + none 各补 2 副本（本轮未触发预注册的 M4 条件，未跑）。
- **mixed 的数据与 lr 混在一起**：两路比较只到"mixed 峰值更高"，不能归因。
- **锯齿形曲线**：48/79 步间隔下的邻点差异可达 7–12 题，其中多少是 checkpoint 本质差异、
  多少是端点负载噪声（共享端点，白天已两次 stream-error 尖峰）无法区分；峰值 20 有被
  噪声高估的可能。
- **端点共享**：available_bsz 波动、他人请求、两次服务端 stream error 都会进入单副本采样。
- `decision_protocol_invalid` 结局与传输作废混在一个计数里；本轮全部 run 作废为 0，无需拆分。
- notool 12 题全部在干净子集内，m432 的 9/12 优势没有泄漏问题，但单类样本量小。
