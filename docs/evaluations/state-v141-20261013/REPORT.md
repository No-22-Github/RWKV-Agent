# v1.41 state 跑分（train-1-41）— 报告

日期：2026-10-13。计划见 [PLAN.md](PLAN.md)，训练脚本 [train-1-41.sh](../../../bench/distill/tools/train-1-41.sh)，测试脚本 [test-1-41.sh](../../../bench/distill/tools/test-1-41.sh)，汇总脚本 [summarize.py](summarize.py)。

## 0. 结论

1. **v1.41 训练有效，三项都不低于 v1.3，其中两项显著更好。** 拿推荐点 `v141b-s1224` 与 v1.3 推荐点 `v13b-s688` 比较，三次结果按题合并：
   - workbank 干净 112 题：25.0 对 22.7，好 17 / 差 17（p = 1），**持平**。
   - bfcl-product：41.0 对 24.3，好 31 / 差 10（p = 0.0015），**回到基模水平**（基模 44）。v1.3 以来的 bfcl 掉分基本修好。
   - bashprobe（V2）：9.0 对 2.0，好 11 / 差 1（p = 0.006）。**b12 教会了模型用 bash。**
2. **推荐点为 `v141b-s1224`**（lr1e-2，第 1224 步）。三个候选在 workbank 上分不出（均值 24.0 / 24.0 / 25.0）。`v141a-s1224` 的 bfcl 最高（44.7），但 bashprobe 只有 4.7（3 次分别为 8 / 3 / 3），比 b-s1224 差（好 3 / 差 10，p = 0.09）。`v141a-fin` 与 b-s1224 三项都分不出，但 bashprobe 的波动大得多（14 / 6 / 7，b-s1224 是 10 / 8 / 9）。
3. **训练末段有效，早期点不跑了。** 两路的 1071 步在三项上都低于 1224 和终点，bfcl 的 irrelevance 掉得最多（7–9 对 15–18）。918 及更早的 10 个存点没有跑（用户同意按趋势停止）。
4. 两个学习率的终点附近分不出，和 v1.3 结论一样。

## 4. 观察

- **bfcl 回升主要来自 irrelevance**：v1.3 是 6–8/20，v1.41 候选点是 15–18/20，"不该调用时不调用"学会了。中文 40 题也从 13–20 回到 20–29，但仍低于基模的 33。
- **收尾阶段吐工具调用基本消失**：bashprobe 中 v1.3 有 12–15 题，v1.41 只有 0–3 题。
- **workbank 零调用变多**：v1.3 为 8–15 题，v1.41 候选为 17–25 题。workbank 总分没有降，但这和 v1.4 数据里零调用占 16.7% 的偏多一致，下一轮配数据时要留意。
- **bash 会用但常做错**：b-s1224 的 bashprobe 有 15–19 题执行了 bash，只对了 8–10 题。下一步应该按 bashprobe 的 probe_axis 拆开看，失分集中在哪类题。
