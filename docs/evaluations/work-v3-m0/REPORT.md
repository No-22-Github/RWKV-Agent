# work-v3 M0：影响面统计（2026-10-19）

规格见 [work-v3-tools.md](../../design/work-v3-tools.md) §2.12、§5 M0。脚本 [m0_stats.py](m0_stats.py)，结果 [stats.json](stats.json)（含全部轨迹编号）。

```bash
python3 docs/evaluations/work-v3-m0/m0_stats.py > docs/evaluations/work-v3-m0/stats.json
```

## 结论

- **一屏 200 行 / 12KB 不改。** 考卷里 read_file 读到的文件，行数中位数 6、p90 约 35，只有 1% 超过 1000 行。会被截成一屏的读取每遍 44–45 次，其中 43 次是被 200 行这一条截的，12KB 只多截 1–2 次。
- **v2.1 训练包要重跑老师的轨迹：8K 包 89 条，16K 包 153 条。** 绝大多数是读到了超过一屏的文件（8K 包 77 条，涉及 54 题）。
- **read_lines 的调用不用重跑。** 8K 包里有 45 条轨迹调用过 read_lines，按 §2.12 改写成带行区间的 read_file 即可，返回内容一样。

## 口径

- "超过一屏"按 §2.1 规则算：超过 200 行，或累计字节超过 12KB。
- "原来报错、新版本会成功"按报错文字匹配，模式写在脚本的 `FIXED` 里。只算 §2.3、§2.9、§2.10 明确放宽的那几类，其余报错照旧。
- 一条轨迹命中多类时只算一次。
