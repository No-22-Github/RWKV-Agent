## 5. 解读与下一步

1. 总分打平 = 网页进步被读取定位类退步抵消。考卷里网页题只有 39 道，这轮数据即便全部生效，总分也只动几题；但对口题上除网页外都没改善。
2. 退步来自数据还是来自换基模（G1L 上 MiSS 效果本身不同）现在分不开：唯一的跨基模对照是不同日、不同基模的 v2.1。
3. **建议的判别实验**：在 G1L 上用 v2.1 训练包（final-20261018）按同参数重训一个适配器（单卡约 2.5 小时），同日与 v2.2 配对跑考卷。差值才是"这轮加的数据"的净效果。
4. 若净效果确为负，先查 b22d（计算器对照组比例）与 b22e（先 wc/head 是否让模型不细读短文件），再决定 v2.3 方向。
