# Qwen3.5-4B 新考卷 2×2：思考 × 采样参数（2026-10-21）

## 结论

**一句话：Qwen3.5-4B 关思考就有 63%，开思考 68%，比我们最好的 G1k + MiSS v2.1（52%）高 11～16 个百分点。采样参数换成官方推荐的，两种思考模式下都分不出差别；开思考是唯一站得住的加分项。**

1. **2×2 四组（每组两遍）**：

   | | T=0.3 / top_p=0.8 | 官方参数 |
   |---|---|---|
   | 不思考 | 358 / 358，均值 358.0（63.0%） | 353 / 364，均值 358.5（63.1%） |
   | 开思考 | 386 / 385，均值 385.5（67.9%） | 392 / 381，均值 386.5（68.0%） |

   官方参数取自模型卡的"通用"档：不思考 T=0.7 / top_p=0.8 / top_k=20 / presence_penalty=1.5，思考 T=1.0 / top_p=0.95 / top_k=20 / presence_penalty=1.5。
2. **采样参数没有影响**：官方参数对 T=0.3，不思考 +66/−64（p=0.93），思考 +79/−83（p=0.81）。换参数翻转的题数和同配置两遍之间的波动一样多。官方参数两遍间的波动更大（两遍不同 93、117 题，T=0.3 为 66、83 题），只跑一遍时 T=0.3 的读数更稳。
3. **开思考 +5 个点，两种采样下都显著**：T=0.3 下 +107/−67（p=0.003），官方参数下 +114/−73（p=0.003）。
   - 加分集中在要算、要写、要读表格的题：compute 63.0→78.5（p=0.003）、write 58.0→68.0（p=0.04）、tabular 32.5→41.0、logs 24.0→33.0、script 10.0→15.0、bashprobe-b14 29.0→36.5；workbank 63.0→75.0（p=0.003）。英文题 +61/−29（p=0.001），中文题不显著。
   - **扣分在 bfcl-product**：49.5→41.5（+4/−12，p=0.08），主要是 bfcl 多轮恢复题，T=0.3 下 10 题里有 8 题从过变成不过。开思考后，模型遇到文件不存在会先问"要不要我读 `owner.txt`"再停下，不思考时则直接读替代文件。这是行为风格的变化，不是协议问题。
   - 思考很短：决策步中位约 110 token，p90 约 350；2800 个决策步里撞到 2048 上限的只有 0～2 次，App 的决策预算够用。
4. **对 v2.1 全面领先**：不思考 T=0.3 对 v2.1 +139/−70（p=2e-6），思考官方参数对 v2.1 +183/−67（p=1e-13）。差距最大的是 write（32→68）、compute（34.5→78.5）、tabular（16→41）、script（2.5→15）。v2.1 只在 bfcl-product（50.5，与 Qwen 不思考持平）、docs、notool 上不落下风。
5. **四组失分分层都判"可以当能力读数"**：协议类失分 ≤0.4%，几乎全部落在 capability 层（321～381 题次）。

## 闸门与作废

- `run check`：八遍都只有采样项 FAIL。闸门表里没有这几档（T=0.3 用 `t03` 档对照，top_p 对不上；官方参数用 `t03` / `t10-p10` 对照，温度、top_p、presence_penalty 对不上），属于有意的设置。步数、两个 token 预算、单题超时、题数 568 全部 PASS。
- **作废与补跑**：两遍叠着跑时，服务端同时排了 380 多个请求，共 9 道题出现单个请求超过 5 分钟拿不到响应（`Client.Timeout exceeded while awaiting headers`）。其中思考官方参数 k0 有 2 道（`tab-0012`、`hyb-8010`），不思考官方参数 k0 有 3 道（`scr-0008`、`bsh-0101`、`wth-0009`）、k1 有 4 道（`scr-0012`、`scr-0018`、`bsh-0014`、`wth-0009`）。这些题已生成的 token 都很少，原因是排队，不是模型卡住。按规程把成品目录挪到 `aborted/`，用原命令加 `--resume` 只重跑这几题：补跑时每题 0.5～2.5 分钟完成，9 题中 5 题通过。八遍最终作废全部为 0。
- 单请求超时目前不能调。以后若继续叠着跑，要么把它做成参数，要么两遍各开约 96 并发，不要都开满 192。
