## 筛选规则

1. **真实可执行与完整性。** 全部入选轨迹必须当前回放 passed，无未监督模型输出，工具调用 JSON 可解析，工具执行成功，训练区间合法，完整长度不超过 4,096 World token。使用 frozen source 哈希，保留原始正文和掩码。
2. **不把现有 pass 当作答案认证。** 原 bank verify 对 `verify_shape_unknown` 会放过。本版默认隔离这些轨迹，仅白名单纳入完整审阅过的 28 条能力边界回答。`nt-5278` 这类题面 SQL 关键词位置错误的轨迹因此被隔离，没有修字后冒充老师原文。
3. **严格答案和产物检查。** 新增非闲聊/非能力边界的 386 条，执行冻结 verify.py 并显式解析其形状：298 个数值、79 个字符串、9 个文件产物（其中 7 个脚本含隐藏未来样本）。未知形状失败；数值答案只能有一个数值，按原题通用精度允许绝对误差不超过 0.01；字符串默认完整匹配。文件检查还核对所有未授权修改的初始文件，脚本在临时目录重新执行。
4. **保留有用调用，排除无谓探索。** 不因使用 calculator 或有多次调用直接判坏。对题面已给足条件的 concept / unit_convert / snippet_in_reply，只允许 calculator；六道确实缺参数、需查本地文件的题明确列例外。重复相同只读调用且中间没有修改会排除。新增路径限制 8 次调用，旧批准样本不套用这一新增偏好。
5. **同题选路。** 先进行质量筛选，再按工具调用数、token 数、稳定 row key 选择更短路径，每个新增原题保留一条。不会截断轨迹、拼接不同路径，也不会删去回执来缩短。
6. **先隔离澄清问题。** 所有新增多轮记录整段排除，避免第二轮训练文本仍携带未经认可的第一轮动作。这里只表示本版不训练澄清行为，不代表这些双轮记录全部无价值。
7. **语义例外审查。** 隔离缺少前提的确定回答，如机柜安装高度被当作外形高度、未约定的真实结算汇率、跨夏令时日期不明、缺实际重量却给计费重量；隔离虚构转达、个人经历、天气及无依据跨会话记忆/运行时断言。保留教师身份表述的历史策略没有被扩展为学生产品事实认证。
8. **纠正用途标签。** `stable_fact` 实际查本地资料的题，在 `meta.cleaning.effective_task_type` 标为 local_fact_lookup；六道需补本地参数题标为 local_numeric_or_reference_lookup。原 case_tags 保留以便追溯。原 `kind=direct` 不能等同于零工具调用。

两个精确、可追溯的字符串例外记录在 `strict_oracles.py` 与每题结果：`fs-5005` 的“Bay B7”对应 oracle “B7”；`fs-5014` 的“Drum 4”对应“4”。两者只是保留显示名称前缀。没有启用任意子串匹配，也没有修改训练文本。

数值与字符串核验依赖题目作者 oracle，不是重新独立推导全部真实世界知识。本轮对题面/终答进行 Agent 内容筛选，并专项审阅能力边界、闲聊及已发现的异常；不把这一过程称作独立多人审查或人工认证。旧 551 条的历史审核结论可在 `source/base700-acceptance-report.md` 查看，当前新增的保证是重新回放和导出一致性。

## 划分与去重

先按旧 parent_seed、新 case family 建立组，再对任务文本与初始夹具计算归一化相似度并合并连通分量。数字归一为 `#`；任务使用 3-gram Jaccard >= 0.55，夹具使用 5-gram >= 0.50，至少 8 个有效特征，去除出现在超过 max(10, 8%记录数) 中的公共模板特征。详细实现和 735 条关系见 `clean.py` / `verification/similarity-edges.jsonl`。

最终 382 组，其中 33 组含旧数据，整组锁定 train；按固定 seed 在其余完整组中选取接近全量 10% 的验证集，得到 train 910、validation 101。新增独立包是对同一切分投影，train 359、validation 101。同题、相同已知家族、被上述规则识别的近重复不会跨 split，精确重复全文为 0；这不意味着消除了所有可能的语义相似。

旧 551 条均带 `seeded_from_test=true`。历史 workbank 的 36 个种子已知污染，不能用全 148 题的分数做干净泛化结论。新题表面 decontam 为零也不是来源独立性证明。

## 格式与训练语义

使用现行 harness v22 / wire hash `707c67403b1b2e5269ddfcd8ecee2bfb7ce4d8133912d102bc67f1324f8018cb`。参考旧 700 的目录、schema_version=2 和 loss_spans 约定，但没有复制旧版渲染正文。source 保留旧 normalized；导出的 normalized 中旧审核字段属于历史，新增 cleaning 明确本轮范围。新增 normalized 工具回执按 JSON 序列化便于检查，实际模型输入仍以 rendered 为准。

混合集 1,999,562 World token，最长 4,091；117 条零调用，占 11.6%。新增集零调用同为 117 条，占 25.4%；合并旧工具任务后比例自然下降。kind 分布：local 608、write 70、web_local 110、script 55、web 25、smalltalk 46、direct 69、refuse 28。

当前相邻训练器 `rwkv_lightning_cuda/src/state_tuning/dataset.cpp` 只支持 text 字段，所以另导出 text-only。该版本做全文 loss，会学习用户提示、系统说明和工具回执；不等同于只监督 assistant 动作。要实现 masked SFT，仍需训练器真正消费 loss_spans。这是训练实现边界，本包没有对训练器做改动或 GPU 验证。
