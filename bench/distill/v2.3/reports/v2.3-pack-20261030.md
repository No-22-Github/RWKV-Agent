去污染只按"文件名相似"标记了 14 题（题面相似度都 ≤ 0.03），按规则跑老师前删掉。

**老师侧的两个问题：**

1. **DeepSeek 跳思考**：b23c 上 DeepSeek 通过 48/65，但 327 步里 102 步没有思考，另有终答超长 15、思考谈论提示词 13、回答语言不对 12，过滤后只剩 31 题。最终 b23c 以千问路径为主、DeepSeek 补位，四个老师合并 51 题有通过路径，过滤后 33 题。剩下 18 题每题都同时有思考超长、缺思考或谈论提示词，没放宽。
2. **Command Code 上的千问工具参数多一个 `}`**：Qwen3.7/3.8 Flash 返回的 arguments 常是完整对象后多一个或多个 `}`，客户端判"不是 JSON 对象"、整题记无效。b23b 第一遍 27/80、b23c 千问 33/65、Qwen3.8-Flash 38/38 无效。已在 `internal/continuation/chatcompletions/client_sdk.go` 加 `trimStrayClosingBraces`：只去掉末尾多余的 `}`，且去掉后必须是 JSON 对象，否则照常报错（带测试）。修后 b23g 第一遍无效 0、通过 36/40；b23b/d/e 用修后的客户端补跑了一遍。
