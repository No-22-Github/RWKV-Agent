# v2.3 计划：以 v2.1 为底重新配平，定向补 G1L 的死因

> **10-30 已出包** [v2.3-pack-20261030](reports/v2.3-pack-20261030.md)（2213 条）。
>
> 2026-10-29 起草，10-30 用户拍板（§8）：NoRA 先训、MiSS 后训；b23c 老师用 Command Code 上的 DeepSeek；10-30 不开训练。
>
> 背景：v2.2 在 G1L、G1K 两个基模上都比 v2.1 低（G1K 同日 286.5 vs 298.0，考卷 v1.1 口径），退步来自数据：b22a 把"题面带公司/产品名就先上网"教给了本地题，8K→16K 补全的 99 道老轨迹试错味重，见 [exam-v22-g1k 报告](../../../docs/evaluations/exam-v22-g1k-20261022/REPORT.md) §4–§7。G1L 基模开思考后的死因排序见 [G1L 原生思考报告](../../../docs/evaluations/irwkv-think-20261029/g1l-7b-temp3797-native-think-exam-report-20261029.md) §2。
>
> 目标：v2.3 在 G1L 上同日配对**明确胜过 v2.1 包**。胜出后再建 RL 基础设施（RL 从 v2.3 适配器起步）；打平或输就先查数据，不上 RL。

## 1. 原则

1. **以 v2.1 正式包为底，不以 v2.2 为底。** v2.2 的新批次逐批过闸门（§4）后择优并入，不整包继承。
2. **每个新行为批次都带反方向对照组**，约占该批 1/4–1/3。v2.1"本地优先"推过头、v2.2"先上网"又推过头，都是只补一头。
3. **配平用数字说话**：出包前跑构成表（§5），任何一项越界就不训练。
4. **轨迹闸门先于判分**：判分只看终答，过程里的空转、复读、点破环境照样进 loss（规则见 §4.4）。
5. **能力题留给 RL**："读对了却数错、算错、取错"占 G1L 失败的 27%，靠蒸馏补题收效不明（v2.2 计划 §1 已有同样判断），v2.3 不专门补。

### 4.3 构造行（主 Agent）

- **R1 被拒后作答**：从通过的多步轨迹里挑"可安全重复的只读调用"，构造"重复 → 被拒 → 用已有结果直接作答"，只训被拒后那一步。171 → 约 300 条，覆盖 read_file / list_files / search_text 三种重复（G1L 重复最多的三个工具）。

### 4.4 轨迹闸门（每批渲染后、出包前，全包跑）

沿用 10-21 的五条：只读工具拿到相同结果 ≥2 次；无写操作的相同调用重发；思考整段照抄上一步；点破模拟环境；搜索年份与题目日期不符。v2.3 新增三条：

- 单步思考 > 900 字；
- ≥2 步思考自述"命令不对 / 被截断 / 换写法"（试错空转）；
- 工具关闭后仍训练工具调用（`scan_forbidden.py`，v2.1 已有）。

命中即整题剔除；剔除清单按原因分类存档。浏览器抽读每批至少 10 条完整轨迹。
