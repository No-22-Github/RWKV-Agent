## Traps
None. The journal records one OPEN line per watering run and the question counts OPEN lines for the fernery bed.

## Reference solution
1. List the workspace: README.md, logs/irrigation.log, notes/head-grower.md.
2. Read logs/irrigation.log and count the OPEN lines with bed=fernery on 2026-07-06: 02:40, 05:10, 11:23, 18:02 = 4.

## Why the answer is unique
OPEN lines are the only record of a valve opening and each carries its bed, so the count of fernery OPEN lines is the count of fernery watering runs. CLOSE lines repeat the same runs and carry no minutes, so no second reading of the journal produces a different count. The answer is 4.
