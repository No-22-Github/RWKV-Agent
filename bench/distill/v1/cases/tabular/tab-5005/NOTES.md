## Traps
- None. The rate is stated in the request and one column carries every figure the calculation needs.

## Reference solution
1. List the workspace: one press run log and a short readme.
2. Read press_runs.csv and add sheets_used: 1840 + 220 + 960 + 1450 + 300 + 2120 + 780 + 240 + 1660 + 540 + 1180 + 320 + 1625 + 860 + 405 = 14500.
3. 14500 x 0.045 = 652.5.

## Why the answer is unique
The allowance is a fixed share of the sheets issued, and sheets_used is the only quantity in the log that can be
meant by sheets issued, one row per run with no repeats. Every run in the log belongs to the same site and the
same accounting period, so 652.5 is the only allowance the file supports.
