## Traps
- TR-NOTOOLNEED: the cask run sheet and the cask table are in the workspace, and the kilderkin is the double firkin the trade has always booked. Taking the firkin row gives 864 imperial gallons.

## Reference solution
No steps; ref_calls is 0. Multiply 96 kilderkins by 18 imperial gallons. The answer is 1728.

## Why the answer is unique
A kilderkin is 18 imperial gallons, so 96 kilderkins hold 96 x 18 = 1,728 imperial gallons. 864 is 96 x 9, the firkin that sits one row below in the same table and is half the size; the run sheet names the cask as a kilderkin and the table keys 18 gallons to that name, so the smaller row does not apply to these casks.
