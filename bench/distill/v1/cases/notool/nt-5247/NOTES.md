## Traps
- TR-NOTOOLNEED: the density sheet sits in the standards folder and the transfer file sits in the transfers folder, but the sand's booking rate is a standing figure; no file has to be opened. Multiplying instead of dividing gives 316.8.

## Reference solution
No steps; ref_calls is 0. Washed sand is booked at 2.4 tonnes to the cubic metre, so divide the 132 tonnes on the ticket by 2.4. The answer is 55.

## Why the answer is unique
Each cubic metre of washed sand weighs 2.4 tonnes, so 132 tonnes fill 132 / 2.4 = 55 cubic metres. 316.8 is 132 multiplied by 2.4, which would make a cubic metre of sand weigh under half a tonne; sand is heavier than water, so the cubic metre figure has to be the smaller number. The limestone and sharp sand rows are other materials, so neither can be the rate that applies to this load.
