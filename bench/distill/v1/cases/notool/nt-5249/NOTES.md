## Traps
- TR-NOTOOLNEED: the energy sheet sits in the standards folder and the return sits in the returns folder, but the megajoule per kilowatt hour is a fixed 3.6; no file has to be opened. Dividing instead of multiplying gives 2347.22.

## Reference solution
No steps; ref_calls is 0. A kilowatt hour is 3.6 megajoules, so multiply the 8,450 kilowatt hours on the log by 3.6. The answer is 30420.

## Why the answer is unique
A kilowatt hour is 3,600 kilojoules, so 8,450 kilowatt hours come to 30,420 megajoules. 2,347.22 is 8,450 divided by 3.6, which would put a kilowatt hour at a third of a megajoule; the return states the month's generation in the larger unit, so the megajoule figure has to be the larger number. The kilocalorie row belongs to a smaller unit still, so it cannot be the figure the return states.
