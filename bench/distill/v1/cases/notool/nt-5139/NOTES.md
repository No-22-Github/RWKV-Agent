## Traps
- TR-NOTOOLNEED: the run sheet and the length sheet are both in the workspace, but a mile is a fixed 1,760 yards and the run length is in the task; no file has to be opened. Leaving the run in metres gives 135184.896.

## Reference solution
No steps; ref_calls is 0. Multiply 84 miles by 1,760. The answer is 147840.

## Why the answer is unique
A statute mile is 1,760 yards, so 84 miles is 84 x 1,760 = 147,840 linear yards. 135184.896 is 84 x 1,609.344, the same run left in metres; the schedule is priced by the linear yard and a yard is shorter than a metre, so the yard figure has to be the larger number.
