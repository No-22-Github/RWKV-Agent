## Traps
- TR-NOTOOLNEED: the stock export and the count sheet are both in the workspace, but a gross is a fixed 144 and the stock figure is in the task; no file has to be opened. Using the dozen row gives 552.

## Reference solution
No steps; ref_calls is 0. Multiply 46 gross by 144. The answer is 6624.

## Why the answer is unique
A gross is twelve dozen, so 46 gross is 46 x 144 = 6,624 single bottles. 552 is 46 x 12, the same stock read against the dozen row; the stock office counts in gross and a gross is 144, so the single bottle figure has to be the larger number.
