## Traps
- TR-NOTOOLNEED: the case declares the zero-call contract (`expect.tools` is empty). This is not a prefix a reader can assemble from the procedure name; a reply that guesses its shape gives ARV-.

## Reference solution
1. Read procedures/ticket-prefixes.txt; the access review request row gives the prefix AREV- (one lookup, matching ref_calls 1).

## Why the answer is unique
The register fixes one prefix per procedure and the README says prefixes do not change for the life of a procedure, so there is exactly one current value on the access review request row. The other prefixes in the file belong to other procedures. The answer is AREV-.
