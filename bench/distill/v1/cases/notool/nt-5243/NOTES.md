## Traps
- TR-NOTOOLNEED: the pressure sheet sits in the standards folder and the test file sits in the tests folder, but the kilopascal per bar is a fixed hundred; no file has to be opened. Multiplying instead of dividing gives 275,000.

## Reference solution
No steps; ref_calls is 0. One hundred kilopascals make one bar, so divide the 2,750 kilopascals on the gauge by 100. The answer is 27.5.

## Why the answer is unique
A bar is a hundred kilopascals, so 2,750 kilopascals is 27.5 bar. 275,000 comes from multiplying by a hundred, which would make a bar a hundredth of a kilopascal; mains run at a few bar and the gauge readings are in the thousands of kilopascals, so the bar figure has to be the smaller number. The psi row is a different unit, so it cannot be the figure the site log holds.
