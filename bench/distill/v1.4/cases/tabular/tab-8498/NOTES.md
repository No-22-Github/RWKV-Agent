## Traps
- TR-NUMFMT: 列 里程 里同一个量混了几种单位写法，直接把数字去掉单位相加（或取最大）得到 800，不是真值。

## Reference solution
1. data_query 按取值分组计数，得到各种写法各出现几次（或各行取值）。
2. 用计算器按 README / 题面口径换算到题目要的单位后汇总。
终答 1-2 句：给出结果 5200，并写明换算口径（例如 1 s = 1000 ms、1 万元 = 10000 元）。判据：包含 5200 的任一写法；read_file 最多 2 次。
