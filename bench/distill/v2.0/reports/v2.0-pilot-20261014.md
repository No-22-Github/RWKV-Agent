## 4. 已知问题

1. **calculator 缺失。** 千问调用 calculator 279 次失败 270 次：141 次把 `precision` 传成字符串 `"1"`（harness 只收整数），其余是失败后原样重试被判重复。含工具报错的路径整条丢弃，所以训练集里没有一次成功的 calculator 调用。修法待定：harness 对整数参数接受数字字符串，或在老师侧另想办法，然后只重跑涉及计算的题。
2. **原生模式强制收尾 bug。** 重复调用被拒后进入强制作答阶段，请求里留下无结果的 tool_call，被 Chat Completions 校验拒掉（invalid user message）。只影响 API 老师，已单独开任务。
3. b20a–c 判据修订见 [b20abc-judge-fix.md](b20abc-judge-fix.md)：补漏收的"做不了"说法、修两道用错词表的题；老师真错（假装已发出、把旧值当现值）保持判错。修订后不重跑老师，由 `corpus paths --include-failed` + 渲染重放重判。
4. 修过的流水线坑：过滤器把裸值/DONE 判成"语言不符"（误丢 69 条）；JSONL 读取按 Python splitlines 规则把 U+0085 当换行（一道题的乱码 fixture 触发），改为只按 `\n` 切。
