1. list_files: the workspace holds survey/block-trees-2026.csv and README.md.

## Why the answer is unique
The register is the survey the request names, one row per standing block, and the
counter column holds a plain count for every row. The README records the same
six blocks, so no row is a stray line from another site and no block is counted
twice. The north strip is named in the README as outside the survey, so its trees
are not part of the count and it carries no row in the file. Summing the six rows
gives 684 and the file offers no alternative basis for the same question.
