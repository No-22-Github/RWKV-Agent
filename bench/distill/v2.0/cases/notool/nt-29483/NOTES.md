## Traps
- TR-NOTOOLNEED: a weather concept question that needs no tool; get_weather / bash / file tools are offered but any call (including listing a directory first) is wrong.

## Reference solution
No tool call. Final answer: 晴夜地面向太空辐射散热，无云遮挡热量散失快；云吸收并回射长波辐射，起保温作用。

## Why the answer is unique
Nothing on disk or in a forecast is asked for. The reply must contain one of ['辐射', '散热', '热量', '保温', '吸收', '反射', '温室'].

## Five alternative phrasings of the task
1. 夜里没云的时候为什么降温特别厉害？
2. 有云的晚上为什么不那么冷？云层是怎么保温的？
3. 晴天夜晚降温快的原因是什么？
4. 云对夜间气温有什么影响？为什么晴夜更冷？
5. 解释一下夜间辐射降温，和云量有什么关系。
