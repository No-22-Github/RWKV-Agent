## Traps
- TR-NOTOOLNEED: a weather concept question that needs no tool; get_weather / bash / file tools are offered but any call (including listing a directory first) is wrong.

## Reference solution
No tool call. Final answer: 光速远快于声速，所以先见闪后闻雷；间隔秒数乘约 340 米，或每 3 秒约 1 公里。

## Why the answer is unique
Nothing on disk or in a forecast is asked for. The reply must contain one of ['光速', '声速', '光的速度', '声音的速度', '传播速度', '传播得快', '传播得慢', '三秒', '3 秒', '3秒'].

## Five alternative phrasings of the task
1. 为什么雷声总比闪电晚到？间隔几秒大概能算出多远？
2. 看到闪电后数几秒才听见雷，怎么估计雷电的距离？
3. 闪电和雷声不是同时发生的吗？为什么我先看到后听到？
4. 能靠闪电和雷声的时间差判断雷离我多远吗？原理是什么？
5. 解释一下为什么先闪后雷，以及怎么粗略估算距离。
