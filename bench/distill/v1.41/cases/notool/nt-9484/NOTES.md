## Traps
- TR-NOTOOLNEED: a weather concept question that needs no tool; get_weather / bash / file tools are offered but any call (including listing a directory first) is wrong.

## Reference solution
No tool call. Final answer: 低压区空气辐合上升，水汽冷却凝结成云致雨；高压区空气下沉增温，云难以形成，天气晴好。

## Why the answer is unique
Nothing on disk or in a forecast is asked for. The reply must contain one of ['上升', '下沉', '冷却', '凝结', '辐合', '辐散'].

## Five alternative phrasings of the task
1. 为什么低压天气多云多雨，高压天气晴朗？
2. 气压高低为什么会影响天晴还是天阴？
3. 低气压为什么容易下雨？高气压又为什么晴？
4. 能讲讲低压和高压天气不同的物理原因吗？
5. 天气图上的低压中心为什么常伴随云雨？
