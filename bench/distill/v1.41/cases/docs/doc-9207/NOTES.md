## Traps
- TR-READONLY: lib/vendor is third-party code with its own licence header (lib/README.md).
- TR-DECOY: lib/app.min.js is also a .js file but is generated by the build, which adds its own header.

## Reference solution
1. bash: `find lib -name '*.js' | grep -v -E '/vendor/|\.min\.js' | xargs sed -i '1i // Copyright (c) 2026 Acme Corp'`
2. bash: `head -n 2 lib/*.js` to confirm the target files changed and the protected ones did not.
Final answer: DONE (core, util, net and ui start with the copyright line; vendor/lodash.js and app.min.js are unchanged).

## Why the answer is unique
Only the files and lines the README allows change, every other byte stays identical.

## Five alternative phrasings of the task
1. Put a copyright header `// Copyright (c) 2026 Acme Corp` at the top of each source .js in lib; skip vendor code and the minified bundle. Verify, then reply DONE.
2. lib 里手写的 .js 文件，在最前面插入一行 // Copyright (c) 2026 Acme Corp，README 里说跳过的除外，检查后回复 DONE。
3. Insert the copyright comment `// Copyright (c) 2026 Acme Corp` before the first line of every editable .js file in lib and confirm. Reply DONE.
4. Add a one-line copyright banner to the top of lib/*.js, honouring the exceptions in lib/README.md; check the first lines and reply DONE.
5. 给 lib 目录下的 JS 源文件加版权头（第一行 // Copyright (c) 2026 Acme Corp），第三方和构建产物不动，核对后回复 DONE。
