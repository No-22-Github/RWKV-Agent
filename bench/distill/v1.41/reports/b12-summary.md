# b12 放量汇总（v1.41，b12a–b12s）

口径：`bench/distill/v1.41/teacher/b12*.jsonl` 中去掉 `common/exclude.jsonl` 剔除项后的路径；行 = 每个用户轮一行。老师 deepseek-flash（T=0.3，thinking=auto，k=3，work-v2，后缀未改）。b12 样板 20 题的 12 个可计行不在下面的统计内。

## 1. 规模
- 20 批 b12a–b12s，约 400 道新题；剩余路径 327 条，432 个用户轮行。
- 可计行（covered，按子类，不含样板和 b12a）：M9a 47、M9b 77、M9c 22、M9d 2、M9e 48；M10a 17、M10b 27、M10c 19、M10d 19、M10e 7。b12a 另有约 26，样板 12。

## 3. 老师行为发现
- M9a/M9c/M9d 的 reject 以答案出现后再多调一次 bash 为主（约 70%），后缀未改，靠 `behavior.py` 剔除；把答案设计成单个数字、README 给出口径、不在 README 里点名 look-alike 值，covered 率能从约 18% 提到约 40%。
- 单文件编辑老师会直接用 replace_lines，不算 bash 编辑；编辑题需改 2 个以上文件。
- 数字紧贴汉字（「气温28度」）会被 token 判据判为不合格，已放宽相关题。
- 思考：约 65–88% 的步有思考，p50 约 150–230 字符，中文题的思考几乎都是英文（<3%）。保持原样，待用户决定带思考版怎么过滤。
