## 6. 经验
- 单文件 M9c 的 covered 率约 30%，与 b12j/b12m 持平；答案后复核仍是主要损耗。行号、区段计数这类“grep -n / awk 一次出数”的题最稳，求和、最大值、最长行类老师倾向再核对一次。
- “两个标记之间的行数”类题必须在 README 写明标记行本身是否计入。
- 本批构建依赖 b12m 的引擎：AGG_SRC 新增的三种聚合在 verify 里同样重算，因此破坏测试对新类型有效。
