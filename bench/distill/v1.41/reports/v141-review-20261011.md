## 2. 样板：结果通过率掩盖了行为覆盖缺口

2026-10-11 本地复跑 `bank verify --cases bench/distill/v1.41/cases --strict-shape`：20/20 通过（含破坏测试），但不覆盖下列所有轨迹行为。已有第二轮完整冒烟：`local/runs/distill/v141/smoke/b12-suffix-r2/summary.json` 为 18/20，nosuffix-r2 为 12/20。第一轮分别是 15/19 与 14/20，不应将第二轮写成首次成功。以下只复读产物，没有重跑老师。

对 suffix-r2 用现行 `corpus paths` 在临时目录复抽：18 条路径保留，2 条因失败剔除（`hyb-9016`、`tab-9002`）。20 道题里 8 道调用 bash、7 道调用 get_weather；**保留路径中只有 7 条含 bash、6 条含 get_weather**。这是小样本覆盖事实，不是放量后的比例预测。

### 2.1 零调用负例没有硬约束

`nt-9010` 的 NOTES 与参考解要求零调用，题面是只给 tar 命令、先别执行。第二轮加 suffix 的实际轨迹却是 `datetime → final`，仍通过，且 `corpus paths` 会保留。

原因：题目仅写 `tools: []`，这不是 `forbidden_tools: ["*"]`。因此该题不能凭 passed 就计入「工具在但不该用」的零调用训练行。应明确题面是否禁止一切工具，并让禁止约束与预期零调用一致；同时单独统计真实零调用，不用题类标签代替轨迹行为。

### 2.2 cwd 不保留样板没有覆盖 cwd 恢复

`cfg-9012` 两轮分别用 list_files 和 read_file 完成，完全没有 bash，也没有第一轮 cd。答案正确，但它没有教到「前次 bash cd 不影响本次 cwd」。

不必给所有 M9 题强制 required bash；应在路径筛选时分别验收：结果正确的普通轨迹，以及实际包含跨调用 cd / 根目录同名诱饵 / 第二次从正确路径访问的 M9f 覆盖轨迹。缺少目标行为的路径不能计入 M9f 已完成配额。

### 2.3 调用 bash 仍可能整读与过度探索

`tab-9002` 在第二轮中用 bash 输出多个月份的 CSV，再用 awk 得到正确的 7521.21 后，继续试 paste / bc（命令失败）和 calculator；最后因其他判据未过被剔除。`scr-9007` 在 awk 求和、calculator 换算已有答案后，又用 bash 扫全部状态行。

因此「含 bash」与「一条管道高效聚合、证据够了就停」是不同指标。放量的 S5 应分别检查整表倾倒、输出截断、冗余探测和计算后继续调用；不能把 `read_file` 整读习惯简单换成 `bash cat`。

### 2.4 恢复轨迹与闭环需要按实际轨迹验收

M9d 允许一次失败后恢复，M10 的地标题允许未知地标改传城市；通用 `corpus paths` 会拒绝有 ToolError / ToolRejected 的路径（仅已有 fixture 网页错误例外）。bash 的非零 exit_code 在此次 trace 中可以作为正常 tool_result 返回，未必触发 ToolError。放量前需各用一条真实的「命令缺失恢复」「天气地标恢复」检查抽取与重放能否保留，不能假定所有恢复都被丢，也不能假定规格声明后自动支持。

M9b 的 bash 回查须检查修改的目标内容/范围，不能把任意后续 bash 或 ls 算作闭环；M10b 须回读所写文件。已有 `hyb-9016` 是终答回合通过、整题因产物未满足判据失败的例子，验收应以整题和实际文件为准。

## 3. b12 不能自动修复全集构成

规划中的总数约 3360 建立在旧的 v1.4 约 3000 行上；当前是 3288，直接加 360 行会成为 **3648 行**，work-v2 占 **9.9%**，而不是旧估计的约 11%。行数配额须明确包含样板还是额外新增，均以最后实际保留行重算。

| 指标 | 当前 v1.4 | 加 b12 的影响 |
|---|---|---|
| 首轮零调用 | 361/3040，11.9%，目标 22–28% | 即使额外 360 行全部是单轮零调用，也仅 `(361+360)/(3040+360)=21.2%`，仍达不到 22%；实际 b12 大部分要调新工具，缺口更大 |
| 多轮 | 464/3288，14.1%，目标 ≥15% | 若新增 360 行均为单轮会降至 12.7%；M9f 需按实际多轮行另算。只补新工具并不能解决 |
| 小工具清单 | 174/3288，5.3%，目标约 7% | 若 b12 全用完整 work-v2，变为 174/3648，4.8%；现行轮换保护两个新工具，并不保证清单会小到 ≤5 |
| data_query 调用占比 | 610/9855，6.2%，目标 ≥10% | bash / 天气调用增加分母；若没有额外 data_query 轨迹，占比继续下降。bash 与 data_query 对不同任务应有明确选用边界 |
| 首动作 list_files | 1495/2679，55.8%，目标 ≤40% | b12 的 bash 首动作可能改善，但 360 行配额本身不保证达标，需按保留轨迹模拟；不能靠题类名推算 |

上述是指定假设下的配额计算，不是模型训练效果预测。应先形成「b12 + 零调用 + 多轮 + 小清单 + 数据工具」统一配额；如决定用 bash 部分替代 data_query 的目标，应正式改写验收理由，而不能仍声称原目标全部达成。
