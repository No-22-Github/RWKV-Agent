# b21k 出题报告（v2.1 第三波，题号 33201–33275，共 75 题）

主题：工作区文档任务。生成脚本 `bench/distill/tools/b21k/`。

## 构成
- 子类：draft_document 19（33201–33219）、extract_items 10 + write_structured 9 共 19（33220–33238）、policy_lookup 19（33239–33257）、link_check 18（33258–33275）。
- 中文 52（69%）/ 英文 23；多轮（≥2 个用户轮）29（39%）；难度 L1 49 / L2 23 / L0 3。
- tool_policy：全部写了 must_offer（写文件题轮换 read_file+write_file / read_lines+write_file / bash / +append_file / search_text 组合；问答题轮换 read_file / read_lines / bash / search_text；链接题含 list_files）；24 题另加 never_offer web_search、web_fetch。
- 单个读取文件均 < 1800 个汉字或 < 6000 英文字符（< 3000 token）。无 review_before 用法；写文件题不要求"已保存"，只判最终文件。

## 判据设计
- 起草类：`expect.files` 用 contains，列材料里的关键事实（人名、时间、编号、金额原文），不含容易被改写的格式；多轮题判最终状态（新标题、新增章节、改后的值）。素材文件 `unchanged`。
- 抽取类：格式在题面写死，多数用 `equals`（含过滤、排序、合并的结果）；少数用 contains（价格/条款表）。verify 由 compute() 从 fixture 重算。
- 条款查询：答案取条款里的具体值（数字开 `output_contains_token`），文档里放相近档位（职级、城市等级、金额档、会员/普通）；二轮问另一条款。
- 链接检查：verify 内置解析器从 fixture 算出坏链，必须与题目期望一致；覆盖近似名、大小写、`../`、引用式链接、`%20`、表格内链接、图片、锚点（不算坏）、外部链接（不算）。题面说"只回答坏链"的题用 `output_excludes` 放正常链接名。写报告/补空页/改链接的轮次判文件。
- `output_excludes` 一律只放 UNKNOWN 与上述正常链接名，不放否定短语。

## 已知风险
- 抽取类 `equals` 对格式/末尾换行敏感（沿用 b21b 做法）；老师少写换行会判错。
- 起草类 contains 用原文字符串，老师若改写（如 "14:00-15:30" 写成 "14:00–15:30"）会判错；已尽量选名字、编号、数字。
- 个别问答用 1–3 位数字（如 "3""5""7""2"）靠 token 匹配，配合另一个值的题较稳，单值题有撞数可能。
- 两个 link_check 的 `inc` 为条数（1 或 2），依赖老师在终答里写出条数。
- 起草类 draft 单次判据只看文件，不检查"排除已取消/过时内容"（contains 无法判缺失）。
