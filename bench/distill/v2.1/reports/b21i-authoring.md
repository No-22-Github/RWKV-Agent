# b21i 出题报告（v2.1 第三波，题号 33001–33080，共 80 题，场景 web）

生成脚本 `bench/distill/tools/b21i/`。网页内容、站点名、URL 全部虚构且每题不同。

## 构成
- 子类（task_type）：summarize_page 13、compare_sources 12、lookup_value 20、latest_version 13、error_meaning 11、deprecation 11。其中 14 题是"页面打不开 / 搜索为空"（33067–33080，分布在 lookup/summarize/error/latest/deprecation 各类型下；8 题 fetch 报错、6 题搜索为空）。
- 中文 50（62.5%）/ 英文 30；多轮（2 个用户轮）31（38.8%）。多轮里：第二轮需再打开新页面的有 20 余题（追问第二页、换备用站、用户给链接、纠正名称后重新搜索）。
- 难度：L1 68、L2 12，无 L0（按 lint 的 traps/ref_calls 规则推出）。
- tool_policy：全部写 `must_offer`；77 题 `[web_search, web_fetch]`，1 题只 `web_search`（答案在摘要里的对照题 33028），2 题加 `read_file`（含本地文件对照，33038、33041）。
- 判据：需要打开页面的轮次 `required_tools: [web_fetch]`；数字/版本号开 `output_contains_token`；日期、带单位的值用 `output_contains_any` 收多种写法（`dates()` 含 ISO、中文年月日、英文月名）；打不开/为空用中英文词表（各约 60–100 条，含大小写和弯引号）。终答均未设 `max_output_chars`。

## 判据设计要点
- 对比题（33013–33024）两个来源数值不同，只给正确值，错误值不进 excludes（诚实回答会同时提到两个值）；其中 33013、33014、33020 开 `output_first_line_contains_any`，题面要求"先给结论"。
- 弃用题把"弃用"与"移除"、"停止新建"与"彻底退役"做成两个日期；33065 官方没给移除日期，只判版本 5.0。
- 失败题（33067–33075）第一轮判"如实说明失败"词表 + 必须尝试过 `web_fetch`；33073、33074 页面一个失败另一个可用，判的是用可用页面取到的值；33069/33070 第二轮用户说换备用站，判备用页数值。空结果题（33076–33080）第一轮判"没搜到"词表 + 必须 `web_search`，后三题第二轮线索（链接/真名/纠正名称）命中 fixture，判取到的值或日期。
- verify.py 校验 `files` 摘要，并断言 output_contains 的值确实在 fixture 页面里；`bank verify --strict-shape` 80/80。

## 已知风险
- "下一步建议"（失败题要求给出替代做法）判据字段不支持第二个 any 列表，未单独判分，需靠轨迹筛选；失败题的编造防线只靠"必须出现失败词"，没有 excludes（虚构站点没有可预测的编造值）。
- 失败词表很宽（含"错误""失败"），老师若先编造答案再顺带提到"错误"可能误过。
- `query_match` 用品牌名子串：老师若把中文品牌翻译成英文再搜会得空结果（品牌已尽量取题面原词）。
- 本批所有题可用 web_search + web_fetch 两个工具通过，无 bash 路径；摘要题 ≤2000 字未限制长度，其余题答案本应短，未设 max_output_chars。
- 整题族之间主题相似（价格/版本/公告），去污染若撞题请直接删。

## 老师最可能答错的题
1. web-33064：两个日期（停止新建 2026-12-31 / 退役 2027-06-30），判的是退役日期，老师可能只答前者。
2. web-33065：官方没有移除日期，老师可能编造日期或第二轮答成 `client.sendLegacy()`。
3. web-33022：发改局与水务公司说法冲突，两轮值（3.85 / 180）分属不同页面。
4. web-33073 / 33075：第一页 fetch 失败后是否继续用搜索结果里的另一页；33075 的旧页数值（95 折）不能当现值。
5. web-33079 / 33080：第一轮搜不到，第二轮用户改口后须重新搜索，容易沿用上一轮"没有"的结论。
6. web-33036 / 33044：RC/未发布版本与稳定版、修复版与当前稳定版的区分。
