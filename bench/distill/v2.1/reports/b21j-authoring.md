# b21j 出题报告（v2.1，题号 33101–33180，共 80 题）

主题：不需要调用工具就该直接回答。生成脚本 `bench/distill/tools/b21j/`。所有轮次 `tools: []`（零调用），工作区放无关的小文件（README + 一个便条），答案不依赖它们。

## 构成
- 子类：改写/润色/翻译/缩写 14（rewrite_text）、代码 14（code_help）、稳定常识 13、单位换算 13、闲聊 13、超出能力 13（beyond_capability）。
- 中文约 62 题（77%）/ 英文 18；多轮（2 个用户轮）16（20%）；难度 L0 12（15%）/ L1 68。
- tool_policy：全部不写约束（目录随机）；通过路径不需要任何工具。
- 终答长度：改写与代码题没加 max_output_chars 上限（除非题面要求"一句话/二十字"）；其余题答案很短。

## 判据设计
- 改写：`output_contains` 放必须保留的实体/数字（订单号、人名、日期、金额），`output_excludes` 放要求去掉的内容（粗鲁措辞、手机号、住址、"茶歇"）；`output_format` zh/en 判输出语言。中文日期题面不带空格（"10月8日"），避免空格写法差异。
- 代码：关键标识符（clampPercent、range、None、wc -l、JSDoc 等）+ 解释类关键词的 any 词表。
- 常识/换算：数字用 `expected_number`（in_text）带容差，常识用 contains/any 收中英文说法；1–3 位裸数字开 token。
- 闲聊：只要求零调用（`require_active_no_call`）加语气相关词表，词表宽。
- 超出能力：中英文拒答词表（含"建议你/你可以"这类转向替代办法的说法）+ 假完成排除词表（已拨打/已发送/已转账等），禁写文件工具；不放"没有…"否定短语进 excludes。
- 多轮：第二轮是"再短一点""换成英文""那 1.5 升呢""改写成脚本"等，纯英文第二轮若干。

## 已知风险
- 零调用是硬约束：老师若顺手调 datetime/读 README 就判错；这是想教的行为，但可能拉低老师通过率。
- 闲聊词表宽，只拦"调了工具/UNKNOWN"，不判质量；rewrite 的 contains 关键实体依赖老师不改写数字格式（如"6%"写成"6 percent"会漏，33105 第二轮已收 6%）。
- 单位换算数值依赖老师不四舍五入过头（容差 0.01 到 8 不等）。
- 稳定常识中 33136（光速）、33139（红楼梦续作）用词表收多种说法。
