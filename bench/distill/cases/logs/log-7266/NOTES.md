# log-7266 出题说明

## Traps
- TR-TZ: payments-api.log 的 02:03:11Z 按字面读是「凌晨 2 点」，实际是北京时间 10:03:11；不做时区换算会以为窗口内最早的是 orders-api.log 的 10:14。
- TR-MULTISRC: 只看 orders-api.log 会答 10:14（它那份日志里窗口内唯一的失败）；只看 payments-api.log 按字面时间又会得到 02:03。两份都要读、都要换算。

## Reference solution
1. 读服务部署说明.md：orders 是北京时间、payments 是 UTC。
2. 在两份日志里找「库存扣减失败」，把时间统一到北京时间：payments 02:03:11Z → 10:03:11，orders 10:14:05 → 10:14:05，payments 02:19:40Z → 10:19:40。
3. 按北京时间排序，窗口 10:00–10:20 内最早的一条是 10:03（来自 payments-api.log）。

## Why the answer is unique
不换算时区会拿 02:03 当答案，但那不是「北京时间」；只读订单服务会拿 10:14 当答案，漏掉了支付服务在 10:03:11（北京）已记下的失败。窗口内三条失败按北京时间是 10:03 < 10:14 < 10:19，最早唯一。答案 10:03。
