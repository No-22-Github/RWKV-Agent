# log-7269 出题说明

## Traps
- （本题无声明陷阱，L0 基题：按礼物与起始时刻过滤后求和；19:4x–19:5x 还有 3 条同礼物流水属于晚场之前。）

## Reference solution
1. 读取 gift-stream.jsonl，筛选「礼物=浪漫烟花」且时间在 2026-09-24T20:00+08:00 及以后的记录。
2. 把 13 条记录的收益相加：2×168 + 3×168 + … = 5040.0 元。

## Why the answer is unique
晚场开始前的 3 条浪漫烟花（19:41、19:52、19:58）按题面「20:00 及以后」排除；其余礼物（小心心、空中花园、手写情书、幸运锦鲤）名称不同不会混入。合计 5040.0 唯一。
