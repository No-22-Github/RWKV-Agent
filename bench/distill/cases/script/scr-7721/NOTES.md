## Traps
- TR-DUPROW: orders/2026-09.csv 里 TS-7003 整行出现了两次（平台重试，两行逐字节相同，订单号不变）。按行聚合会把 09-05 记成 2 单 16800 分，合计变成 12 单 71200 分，而平台口径是 10 单 60000 分。

## Reference solution
1. 读 daily.py 的说明文字：一笔订单只算一次，日结单按天聚合。
2. 读 orders/2026-09.csv：TS-7003 出现了两次。
3. 读 README.md：重试的行与原行完全一样。
4. 修 daily.py：按订单号去重后再按天聚合订单数与金额分。

## Why the answer is unique
按订单号去重后，合并两份导出（跑分时会再放入 orders/2026-10.csv，其中 TS-7102 同样重发了一次）正好是 2026-09-02,2,8400 / 2026-09-05,1,8400 / 2026-09-09,1,3200 / 2026-09-16,1,11200 / 2026-09-23,1,5600 / 2026-09-28,1,5600 / 2026-10-08,1,6400 / 2026-10-14,1,2800 / 2026-10-21,1,8400 / 合计,10,60000。说明文字与 README 都写明同一笔订单只算一次，两行逐字节相同且订单号相同，按行照算与平台自己的去重规则冲突，日结单没有第二种成立的理解。
