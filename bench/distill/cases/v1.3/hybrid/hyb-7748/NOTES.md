## Traps
- TR-AMBIG: README 写明供应商按月对账，而题面没说对哪个月的账；把流水里维庚建材全部行合计得 13534.55，是把对账口径当成了全期累计。

## Reference solution
1. 第 1 轮：对账以月为周期，题面未给月份，向用户反问核对哪个月（本轮不调工具）。
2. 第 2 轮：用户答复对 8 月的账。
3. 读 purchases/采购流水.csv，取供应商为维庚建材且日期在 2026-08 的两行：1875.20、3120.75。
4. 合计 4995.95，只报数字。

## Why the answer is unique
 decoy 13534.55 混入了 6、7、9 月的维庚建材采购；用户已把对账周期定为 8 月，按月对账的口径下其余月份不属于本次对账，答案只剩 4995.95。第 1 轮判据只要求指出缺月份。

1. 维庚建材这次对账要算哪个区间的采购额？

3. 算一下维庚建材在我们这进了多少货。
4. 我要维庚建材的采购对账数。
