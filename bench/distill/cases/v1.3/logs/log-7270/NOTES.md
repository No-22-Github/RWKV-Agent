# log-7270 出题说明

## Traps
- TR-MISSING: 已结算的 42 条里有 4 条配送费字段是脏数据（null 两条、缺字段一条、'-' 一条）；把脏记录按 0 元计入分母会得到 513÷42≈12.21，按口径剔除后是 513÷38=13.50。

## Reference solution
1. 读结算口径说明.md：只统计「已结算」，配送费为空值/缺字段/'-' 的脏记录不计入合计与分母。
2. 读 rider-trace.jsonl，取 38 条配送费齐全的已结算记录，合计 513.0 元，平均 513.0÷38 = 13.5 元。

## Why the answer is unique
已结算的记录共 42 条，但其中 4 条没有可用金额（口径写明剔除），参与平均的只有 38 条；把脏记录当 0 元会得到 12.21 的诱饵值。「已退款」「超时未接」的记录即使带金额也不参与统计。口径唯一，答案 13.5。
