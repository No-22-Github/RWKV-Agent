## Traps
- TR-CLAIM: the day-shift tally line near the top claims 9 sensor-drop events 'so far', written mid-morning long before the day's events landed; the README marks it a running operator note. The journal actually records 17.

## Reference solution
1. Read README.md: line grammar and the status of the tally line.
2. Search 'sensor drop' and read the line windows around the hits.
3. Keep only CRITICAL lines whose message opens with 'sensor drop'; the clock-drift CRITICAL lines stay out.
4. The count is 17.

## Why the answer is unique
The tally line is a partial mid-morning note, not a journal record, so it cannot bound the count; the clock-drift lines are CRITICAL but their message opens differently. The count of sensor-drop CRITICAL lines is 17.
