## Traps
- TR-MISSING: slips/2026-09.csv 的件数列里两种空值形态同时在场（09-14 鞋靴是空格子，09-28 皮具是短横线），都会让 int() 抛 ValueError；只处理其中一种，下个月导出（10-16 春装是短横线）仍会中断。

## Reference solution
1. 读 logs/夜批-2026-09-28.log：中断是 ValueError，int('')。
2. 读 wash.py：件数一格直接进 int()。
3. 读 slips/2026-09.csv：空格子和短横线两种格子都在。
4. 读 README.md，把 wash.py 修成两种格子都按零计入。

## Why the answer is unique
空格子和短横线都按零计入后，合并两份洗涤单（跑分时会再放入 slips/2026-10.csv，其中春装是短横线）正好是 春装,75 / 毛衣,83 / 皮具,18 / 鞋靴,12 / 合计,188。说明文字与 README 同时写明两种格子按零计入，删除整行或只认一种格子的修法都会在另一份导出上再次中断，没有第二种成立的口径。
