## Traps
- TR-NEARNAME（恢复题，恢复行为是考点）: 题面只说「按月结口径发运最多的单品」，表里没有叫「发运箱数」的列，只有一对近名列：生产箱数（含留样与待检）与出厂箱数（月结按实际发运结算）。第一次用猜测的列名聚合会收到 `field "..." is missing` 报错；filter 引用不存在的列则返回 matched_rows 0。模型要从报错或空结果恢复：用不带 operation 的 data_query select 列出真实表头（或用预算内最多一次 read_file 看表头），再改用出厂箱数分组求和。README 写明月结按出厂箱数。
- 顺手聚合生产箱数，最多的单品共生产 2462 箱；正确答案是出厂箱数合计最大的 椒盐粉，共 1859 箱。

## Reference solution
1. 读 README.md：生产箱数含留样与待检，月结按出厂箱数。
2. 查询：{"path":"data/packing_2026-09.csv","filter":{"批次月份":"2026-09"},"operation":"sum","field":"出厂箱数","group_by":"单品"}，取合计最大的椒盐粉，得 1859。（若第一次猜错列名报错：先 select 看全部列名，再按本步重查。）
3. 终答只报数字 1859.0。
