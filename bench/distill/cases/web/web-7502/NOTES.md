## Traps
- TR-WEBSTALE: the datatooljournal post announcing 2.5.0 ranks first
  (published 2026-04-11); the official changelog (published 2026-09-12) lists
  2.8.4 as the current stable release.

## Reference solution
1. web_search kestrel cli changelog (1)
2. web_fetch the blog post: 2.5.0, April (2)
3. web_fetch docs.kestreldata.example/changelog: 2.8.4 (3)

## Why the answer is unique
The changelog is the vendor's own release history with in-content dates, and
its newest stable entry is 2.8.4 (2026-09-12). The blog's 2.5.0 is itself an
entry in that same history and is superseded by two later releases, so it is
a past version rather than a defensible reading of "current stable", and
2.8.4 is the only string a new machine can pin today.

## Five alternative phrasings of the task
1. kestrel cli changelog release history
2. kestrel cli current stable version
3. which kestrel cli version should we pin
4. kestrel cli version for new installs
5. kestrel cli release notes changelog
