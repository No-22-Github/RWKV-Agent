## Traps
- TR-EARLYHIT: the first result is Sedgebrook's own notice for the v9 contact
  importer and its snippet states the 145 day period, so one search is enough and the
  case caps web_search at 1. The report endpoint notice is the decoy: its 220 days
  covers the v9 report endpoints, a different set of endpoints, and that page says the
  two notices run on separate clocks.

## Reference solution
1. Search for the Sedgebrook contact importer notice: it is the first result and its
   snippet carries the period, with the report endpoint notice beside it.
2. Open sedgebrook.example/notices/contact-importer-v9: the importer keeps accepting
   uploads for 145 days from the publication date and is then switched off.

## Why the answer is unique
The notice names the component it covers and attaches one period to it, counted from
its own publication date. SB-8802 is the code a late upload is refused with rather
than a period. The 220 days belongs to the report endpoints, a separate notice the
page itself says runs on a different clock, so it cannot be the period for the
importer the onboarding team uses.
