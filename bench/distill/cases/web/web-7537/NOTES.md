## Why the answer is unique
The changelog is the vendor's own release history and marks exactly one entry
as current stable, 3.14.2 (2026-09-05). Older entries 3.13.0 and 3.12.4 are
past releases by construction, and the download page carries no version
string at all, so 3.14.2 is the only string a new workstation can pin.
