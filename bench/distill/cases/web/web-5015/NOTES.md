## Traps
No traps. One search returns the Quarryside error page and the row states the
ceiling in the same sentence as the meaning.

## Reference solution
1. Search for the Quarryside bulk import errors; the only result is
   docs.quarryside.example/errors/bulk-import.
2. Open the page: QR-8802 is raised when one import carries more than 2500 rows.

## Why the answer is unique
The page gives one ceiling and attaches it to the code whose meaning is an import
too large, which is the code the nightly load is refused with. QR-8801 covers a file
whose first line is wrong and QR-8804 covers a key scope, so neither describes a
ceiling. The page adds that the ceiling belongs to one import rather than to the
file, so the figure that applies to a single refused import is 2500.
