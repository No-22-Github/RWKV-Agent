## Traps
- TR-WEBSTALE: 搜索结果里论坛帖（v4.0.0-beta，发布日期 2026-09-14）比官方发布页（v3.9.1，2026-09-10）更新，且抢先体验包并非稳定版；按「日期最新」取版本会写成 v4.0.0-beta。
## Reference solution
1. 查昆仑组件官方发布页，当前稳定版为 v3.9.1（beta 帖不是稳定版）。
2. 打开 部署清单.txt，把首行「当前统一版本：v3.8.2」更新为「当前统一版本：v3.9.1」。
3. 回答新版本号 v3.9.1。
## Why the answer is unique
官方发布页写明当前稳定版为 v3.9.1、v4.0.0-beta 仅供测试环境，生产清单按 README 的口径应更新为稳定版；「当前稳定版」在发布页只有 v3.9.1 一个指称，因此清单新值唯一。
