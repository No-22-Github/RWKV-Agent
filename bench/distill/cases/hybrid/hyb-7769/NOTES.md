## Traps
- TR-AMBIG: two Brayford suppliers keep separate delivery files; summing both gives 86 cases and answers a question nobody asked. Turn 1 must name both files and ask which supplier is meant.

## Reference solution
1. Turn 1: list the deliveries directory, find the two Brayford files, name both and ask which one is meant.
2. Turn 2: the user picks the Creamery file.
3. Read deliveries/deliveries-brayford-creamery.csv and sum the cases column: 14 + 12.
4. Total 26 and reply with the number alone.

## Why the answer is unique
 The decoy 86 merges the Farms file (36+10+40); once the user pins the Creamery file the Farms rows are outside the scope and the only reading is 26 cases.

## Five alternative phrasings of the task
1. How many cases arrived from Brayford this month?
2. Count the Brayford delivery cases for September.
3. Add up the cases Brayford brought us.
4. What was Brayford's September case count?
5. Total the cases delivered by Brayford.
