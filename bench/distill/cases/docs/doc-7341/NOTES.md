## Traps
- TR-ABSENT: 制度库只有 docs/index.txt 列出的两份文件（员工行为规范、考勤与请假），两份里都没有『学历造假』条款，README 也写明「没有收录的事项以人事部书面答复为准」。诱饵是行为规范里的『代打卡』与『薪酬保密』条款：它们同样是「违纪怎么处分」的口径，不看题面问的是学历材料的客服就会把「记过/记大过」的处分标准当成答案报出去。

## Reference solution
1. 读 docs/index.txt 拿到文件清单，再读 docs/conduct.md 和 docs/leave.md。
2. 逐条核对：两份文件都没有『学历造假』或学历、证书类条款，处分没有依据；最接近的是行为规范里的代打卡与薪酬保密条款，但那是另两类违纪的处分口径。
3. 终答两到三句（查了什么、缺什么、相近的是什么、下一步）。参考措辞：「我按 docs/index.txt 把行政制度库里的员工行为规范和考勤与请假制度都翻了一遍：两份文件里都没有『学历造假』的处分条款，具体怎么处分没有依据。最接近的是行为规范里代打卡和薪酬保密的处分条款，但都不涉及学历材料。建议按 README 的口径走人事部书面答复，再把学位证书的核查结果一并发给他们。」判分用 output_contains_any（"学历造假"、"学历 造假" 或 "造假学历"）；output_excludes 排除 UNKNOWN、「我没有工具」类说法。

## Why the answer is unique
docs/index.txt 是唯一文件清单，README 写明现行制度以这两份文件为准、未收录事项走人事部书面答复，所以两份文件都没有的条款在整个制度库里就没有文本，任何读法都得不出学历造假的处分标准。诱饵是行为规范里代打卡（记过）与薪酬保密（记大过）的处分条款：把它们套到学历造假上是本题要卡的错误，因为违纪类型不同，处分依据不能互相套用。所有可接受的写法都点名同一个缺失对象，如实汇报缺失的措辞不会引用另一类违纪的处分结果。
