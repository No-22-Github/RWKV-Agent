## Traps
- TR-NEARNAME: archives/ holds repair-2026-09.txt and the similarly named
  superseded-2026-08.txt; the latter is the closed August ledger kept for
  record only. Pulling rows from the superseded file (《雪堂行拾》 again, or
  the already-finished 《澄清堂帖》) is the trap.

## Reference solution
1. Read README.md: the weekly list comes from the current month's repair-YYYY-MM.txt, takes only 待修 rows, and is written `- <书名> <病况>` in row order into pending/ named after the tidy-up date; superseded- files are closed.
2. Read both archives files and tell them apart.
3. Read the rows of archives/repair-2026-09.txt.
4. Write pending/2026-09-26.txt with the three 待修 lines.

## Why the answer is unique
README 把派工来源固定为当月 repair 文件，superseded-2026-08.txt 明确写为
留底不派工，两个文件名虽然相近但只有一个是当月档案；行序、行式与文件名
也由 README 固定，清单只有一种。
