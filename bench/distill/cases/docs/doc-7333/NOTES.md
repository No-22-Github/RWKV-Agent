## Traps
- TR-SIGN: 差异数量为有符号数，README 写明正数=多收、负数=短少；把「多收」理解成绝对值最大或统计负数行会答 8（短少条数）。

## Reference solution
1. 读取 到货差异登记.tsv，按差异数量大于 0 过滤：CY-1101（12）、CY-1105（8）、CY-1108（30）、CY-1112（4）、CY-1116（22）。
2. 对照 README.md 确认正数即多收。

作答：5。

## Why the answer is unique
短少（负数）恰为 8 条、账实相符 5 条、多收（正数）5 条，三种互斥；「多收」由 README 的符号约定唯一定义为正数，答案唯一为 5。
