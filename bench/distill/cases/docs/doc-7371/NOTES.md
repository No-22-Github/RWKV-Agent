## Traps
- TR-DECOY: the September archive has four rows, but 《灵岩县志》残卷 is
  marked 已修完 归架. Copying all four rows onto the pending list is the trap.

## Reference solution
1. Read README.md: rows whose 状态 is 待修 go on the weekly list, one line `- <书名> <病况>` in archive order, file named after the tidy-up date.
2. Read archives/repair-2026-09.txt.
3. Write pending/2026-09-25.txt with the three 待修 lines.

## Why the answer is unique
清单只收状态=待修的条目；县志残卷已经修完归架，档案里没有让它回到
待修的任何依据，把它列进清单等于重复派工。其余三行书名与病况照抄档案，
行序与文件名由 README 固定，清单只有一种。
