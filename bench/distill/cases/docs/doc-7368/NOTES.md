## Reference solution
1. Read README.md: settled note items are entered the same day with the fields 日期 品名 数量 途径 结算 经手.
2. Read notes/purchase-2026-09-29.txt.
3. Append the 缆绳 line dated 2026-09-29 to logbook/supply-2026-09.txt.

## Why the answer is unique
The note carries one item with its date, quantity, route, settlement and
handler, and the line shape is fixed by the existing ledger rows, so the
appended line has exactly one possible content.
