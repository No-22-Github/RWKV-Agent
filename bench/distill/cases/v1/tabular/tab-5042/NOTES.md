## Traps
- None. Every block carries its own turf count and the levy is a single rate applied to the total lifted.

## Reference solution
1. List the workspace: the May cutting file and a short readme.
2. Read turf_cutting_2026-05.csv, add the turf_count column (19130 turfs) and multiply by 1.85 pounds a turf: 35390.5 pounds.

## Why the answer is unique
The readme states one row per block and gives turf_count as the turfs lifted from that block, so the rows add up to the turfs lifted in the month and the levy is that total at the stated rate. Turfs of a block are not counted anywhere else in the log, so the count is 19130 and the levy is 35390.5 pounds.
