## Traps
- TR-NOTOOLNEED: the charge sheet sits in the standards folder and the test sheet sits in the tests folder, but the coulomb per ampere hour is a fixed conversion; no file has to be opened. Dividing instead of multiplying gives 0.0125.

## Reference solution
No steps; ref_calls is 0. An ampere hour is 3,600 coulombs, so multiply the 45 ampere hours on the test sheet by 3,600. The answer is 162000.

## Why the answer is unique
An ampere is a coulomb a second, so an ampere hour is 3,600 coulombs and 45 ampere hours come to 162,000 coulombs. 0.0125 is 45 divided by 3,600, which would make an ampere hour a three-thousand-six-hundredth of a coulomb; the test sheet records the charge the string holds, so the coulomb figure has to be the larger number. The ampere second row is a different unit again, so it cannot be the figure the schedule carries.
