## Reference solution
No steps; ref_calls is 0. Each carton takes 1.2 linear feet, so 84 cartons take 84 x 1.2 = 100.8 linear feet.

## Why the answer is unique
The allowance is a shelf space per carton, so the count of cartons multiplies it: 100.8 linear feet. The decoy 70 comes from dividing one figure by the other, which answers how many cartons fit a foot rather than how much shelf the collection needs. The card repeats the allowance and the count, so both sources give 100.8.
