## Traps
- TR-NOTOOLNEED: the bake profile and the scale factor sheet are in the workspace, but the Celsius to Fahrenheit rule is a standing one and the profile is in the task; no file has to be opened. Dropping the offset gives 335.7.

## Reference solution
No steps; ref_calls is 0. Multiply 186.5 by 1.8 and add 32. The answer is 367.7.

## Why the answer is unique
Degrees Fahrenheit are nine fifths of a degree Celsius plus a 32 degree offset, so 186.5 degrees Celsius is 186.5 x 1.8 + 32 = 367.7 degrees Fahrenheit. 335.7 is the same profile with the offset left off; the offset applies to every reading, so the Fahrenheit figure has to be the larger number.
