## Traps
- TR-NOTOOLNEED: the docket and the typesetting unit sheet are in the workspace, but a point is a fixed seventy-second of an inch and the depth is in the task; no file has to be opened. Treating the depth as picas gives 180.

## Reference solution
No steps; ref_calls is 0. Divide 2,160 points by 72. The answer is 30.

## Why the answer is unique
There are 72 points to the inch, so a 2,160 point banner is 2,160 / 72 = 30 inches deep. 180 is 2,160 / 12, the depth counted in picas; the setting sheet is written in inches and a point is a twelfth of a pica, so the inch figure has to be the smaller number.
