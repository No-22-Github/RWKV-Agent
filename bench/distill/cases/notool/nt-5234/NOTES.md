## Traps
- TR-NOTOOLNEED: the trip card carries both legs and the payload, so the work follows without opening anything. Counting the empty return leg as loaded gives 5940.

## Reference solution
No steps; ref_calls is 0. Only the loaded leg carries the 22.5 tonnes, so the work is 132 kilometres times 22.5 tonnes, or 2970 tonne-kilometres.

## Why the answer is unique
An empty leg carries nothing, so only the loaded 132 kilometres count: 2970 tonne-kilometres. The decoy 5940 counts the return leg as if it carried the payload too, which measures the distance the truck ran rather than the work it did.
