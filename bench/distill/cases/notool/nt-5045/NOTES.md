## Traps
- TR-NOTOOLNEED: the case declares the zero-call contract (`expect.tools` is empty). Guessing a form number from the petition name is not possible; the neighbouring row is the trap and gives MTR-14.

## Reference solution
1. Read registry/forms-index.txt; the late withdrawal petition row carries form number LWP-9 (one lookup, matching ref_calls 1).

## Why the answer is unique
The index holds one row per form, and the README says a form number is issued once and kept for life, so there is no second number for a late withdrawal petition. MTR-14 belongs to the module transfer request. The answer is LWP-9.
