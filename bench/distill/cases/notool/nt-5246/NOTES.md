## Traps
- TR-NOTOOLNEED: the frequency sheet sits in the standards folder and the test file sits in the tests folder, but the revolutions a minute per hertz is a fixed sixty; no file has to be opened. Multiplying instead of dividing gives 207,000.

## Reference solution
No steps; ref_calls is 0. Sixty revolutions a minute make one hertz, so divide the 3,450 revolutions a minute by 60. The answer is 57.5.

## Why the answer is unique
One hertz is one cycle a second, so 3,450 revolutions a minute is 57.5 hertz. 207,000 comes from multiplying by sixty, which would make a hertz sixty times a revolution a minute; a set running at 3,450 revolutions a minute runs a little under 58 hertz, so the hertz figure has to be the smaller number. The radian a second row is a different unit again, so it cannot be the setting the relay takes.
