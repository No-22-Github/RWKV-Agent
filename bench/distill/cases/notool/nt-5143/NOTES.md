## Traps
- TR-NOTOOLNEED: the pop sheet and the throughput unit sheet are in the workspace, but a megabit a second is 0.45 gigabytes an hour at decimal sizes and the peak is in the task; no file has to be opened. Using the binary row gives 301.75.

## Reference solution
No steps; ref_calls is 0. Multiply 720 megabits a second by 0.45. The answer is 324.

## Why the answer is unique
720 megabits a second is 90 megabytes a second, which is 90 x 3,600 = 324,000 megabytes an hour, or 324 gigabytes an hour at decimal sizes. 301.75 is the same peak read against the sheet's binary row; the report states gigabytes and a gibibyte is the larger unit, so the decimal figure has to be the larger number.
