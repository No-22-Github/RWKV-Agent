## Traps
- TR-AMBIG: the first message never says which run Petra is on and carries no distance or consumption figure, so no litres figure can be computed from it; the correct first move is to ask and call nothing. On the clarified turn the careless value is 2675, obtained by multiplying 214 by 12.5 instead of dividing.

## Reference solution
1. Turn 1: ask which run the diesel figure is for; no tool calls (ref_calls 0).
2. Turn 2 (Keswick run named with distance and consumption): 214 / 12.5 = 17.12 litres; no tool calls.

## Why the answer is unique
The clarified message gives the distance in km and the consumption as km per litre, so litres = km divided by km per litre and 17.12 is the only figure the text supports. The decoy 2675 multiplies the two numbers, but kilometres times kilometres-per-litre is not a volume in litres under any reading of the message, so it is not a defensible answer; no other operation on the two stated quantities answers a litres figure.
