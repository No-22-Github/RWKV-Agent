## Traps
- TR-NOTOOLNEED: the case declares the zero-call contract (`expect.tools` is empty). The revision is not derivable from the standard name, so a reply written from the usual pattern gives ACS-3, one revision behind the register.

## Reference solution
1. Read standards/revision-register.txt; the access control standard row holds ACS-4 (one lookup, matching ref_calls 1).

## Why the answer is unique
The register lists one revision per standard and the README states superseded revisions are archived and not listed, so ACS-4 is the only revision recorded for access control and the one an audit reads. The answer is ACS-4.
