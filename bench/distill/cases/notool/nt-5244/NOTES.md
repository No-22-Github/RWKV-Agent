## Traps
- TR-NOTOOLNEED: the speed sheet sits in the standards folder and the passage log sits in the runs folder, but the kilometre an hour per knot is a fixed 1.852; no file has to be opened. Dividing instead of multiplying gives 9.45.

## Reference solution
No steps; ref_calls is 0. A knot is one nautical mile an hour and the nautical mile is 1,852 metres, so a knot is 1.852 kilometres an hour. Multiply the 17.5 knots by 1.852. The answer is 32.41.

## Why the answer is unique
A knot is a nautical mile an hour and the nautical mile is the longer mile, so the kilometre an hour figure has to be the larger number: 17.5 x 1.852 = 32.41. 9.45 is 17.5 divided by 1.852, which would make a knot nearly two kilometres an hour; the metre a second row is a third unit again, so it cannot be the figure the survey report is written in.
