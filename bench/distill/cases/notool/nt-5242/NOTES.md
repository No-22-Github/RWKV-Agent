## Traps
- TR-NOTOOLNEED: the count sheet sits in the standards folder and the yarn order sits in the specs folder, but the denier per tex is a standing multiplier; no file has to be opened. Dividing instead of multiplying gives 2.67.

## Reference solution
No steps; ref_calls is 0. A tex is nine denier, so multiply the 24 tex order by 9. The answer is 216.

## Why the answer is unique
The denier is the finer count: one tex of yarn weighs 9 denier, so 24 tex is 216 denier. 2.67 is 24 divided by 9, which would make a denier nine times coarser than a tex; the spinner's note is written in tex, so the denier figure has to be the larger number. The decitex row is a tenth of a tex rather than a denier, so it cannot be the count the materials system holds.
