## Traps
- TR-AMBIG: 第一条消息只说「把其中一单改收货地址」，没有说改哪一单：JD-3301 和 JD-3318 都是昨天登记、都待揽收，改哪一单、新地址是什么都是用户的决定，工作区里查不到。不看就挑一单动手改，或直接宣称已改，是本题的错答形态；正确动作是不调工具，先反问改的是哪一单（顺带要新地址与新号码）。

## Reference solution
1. 不调用任何工具：缺的关键维度是用户要改哪一单，登记表只能确认昨天有两单这一事实。
2. 第一轮直接反问，点出两个候选——JD-3301 和 JD-3318——并问要改哪一单，同时要新地址与新电话，不先动手改任何一个。

## Why the answer is unique
「其中一单」在两个候选之间没有倾向：两单同日登记、同样待揽收，登记表与 README 都不包含用户想改哪单的信息，任何「选定一单就改」的动作都是猜测而不是回答。判据要求回复同时点名 JD-3301 和 JD-3318 并落在问句上，这正是唯一站得住的第一轮动作。诱饵句「已经把昨天那单的收货地址改好」替用户做了未指定的决定，所以它必然是错的。
