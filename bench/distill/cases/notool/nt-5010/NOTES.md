## Traps
- TR-NOTOOLNEED: the imposition card exists in the workspace, yet every figure the term needs is in the question. The decoy 26880 treats the two faces as two copies of the same pages.

## Reference solution
No steps; ref_calls is 0. Each sheet yields 8 pages on each face, so 16 pages, and 840 sheets give 13440 finished pages.

## Why the answer is unique
An imposition sheet holds a different set of pages on each face, and the run puts every page of the programme on the sheet once, so the two faces add up rather than repeat: 840 x 8 x 2 = 13440. The decoy 26880 counts each page twice. The card states the same sheet count and page count, so the workspace cannot answer otherwise.
