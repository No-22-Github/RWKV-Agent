## Traps
- TR-NOTOOLNEED: the rate sheet sits in the standards folder and the order file sits in the invoices folder, but the desk rate is a standing figure; no file has to be opened. Dividing instead of multiplying gives 721.03.

## Reference solution
No steps; ref_calls is 0. Multiply the 8,400 euro order by the desk rate of 11.65 kroner to the euro. The answer is 97860.

## Why the answer is unique
A euro buys about eleven and a half kroner, so an 8,400 euro order posts at 8,400 x 11.65 = 97,860 kroner. 721.03 is 8,400 divided by 11.65, which would make a euro worth a fraction of a krone; the ledger posts the supplier's order in kroner, so the kroner figure has to be the larger number. The Swedish row is a different currency, so it cannot be the rate this order posts at.
