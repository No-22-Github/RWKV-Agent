## 定案：Qwen3.8-27B 采三遍

批次 b22c-q38-27b、-s2、-s3。两遍同时跑、共 16 路时 Command Code 对 Qwen3.8-27B 回 429，改为 6 路逐遍跑。三遍分别过 33/50、35/49、33/49（各 1 道 429）。

```bash
bench/distill/tools/v22/render_pick.sh b22c-q38 b22c-q38-27b b22c-q38-27b-s2 b22c-q38-27b-s3
```

每遍只取通过的路径，按遍的顺序，每道题留第一条过 filter.py（另加 `--require-reasoning --max-step-reasoning 900`）的。结果：**27 道题、72 行**。101 条通过路径里，丢弃原因：同题已有 39、终答超 600 字 19、单步思考超 900 字 15、思考提 system prompt 9、只要值却用 Markdown 3。终答上限放宽到 1000 字只多 4 道，没放宽。

三遍都没过的 13 道：doc-34231、hyb-34221、hyb-34225、hyb-34246、log-34236、web-34204、web-34205、web-34218–34220、web-34222–34224。长网页那 7 道要找的事实都在 6K 截断以内（抓取结果里有），不是截断造成的，留待查题或判分。
