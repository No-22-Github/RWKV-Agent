2. 用 data_query 聚合：{"path":"data/site_fees.csv","filter":{"入住月份":"2026-09","营位类型":"临湖营位"},"operation":"sum","field":"结算金额"}，得 5286.21。（若第一次猜错列名报错：先发一次不带 operation 的 select 看到全部列名，再按本步重查。）
