## Traps
- TR-DECOY: intake/2026-09.csv 里有两行状态为「已撤销」（A07 青菜 20 件、B02 带鱼 25 件），除此之外与正常行完全一样。把它们照算会得到 425 件，而台账口径是 380 件。

## Reference solution
1. 读 ledger.py：说明文字已把版式和「已撤销」的处理定死。
2. 读 intake/2026-09.csv，确认列和两行「已撤销」。
3. 写 ledger.py：只统计状态为「入库」的行，按摊位号聚合件数，排序输出，末行合计。

## Why the answer is unique
只算「入库」行时，合并两份记录（跑分时会再放入 intake/2026-10.csv，其中也有一行「已撤销」）正好是 A03,90 / A07,165 / B02,45 / B05,80 / 合计,380。版式与撤销口径由 ledger.py 的说明文字和 README 同时定死；把「已撤销」行照算的 425 件读法，与导出文件里状态列自己标注的含义冲突，台账没有第二种成立的理解。
