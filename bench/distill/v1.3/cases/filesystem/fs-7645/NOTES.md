## Traps
- TR-DECOY: 导出/作废 子目录里还有两份首行为「类型：台账」的导出（export_0077.txt 等）。不读 README 的回滚说明、按目录全扫会得 5。
## Reference solution
1. 列出 导出 目录，看到五份顶层导出和 作废 子目录。
2. 读 README 的导出说明：作废 子目录里的导出已回滚、不算有效。
3. 逐份看顶层导出的首行类型戳，台账类为 export_0081、0083、0085，回答 3。
## Why the answer is unique
README 写明作废子目录不属于有效导出，因此答案只能是顶层五份中的台账数 3；把作废目录算进来的 5 是违背 fixture 规则的错答，其余类型戳（日报、通知）在首行写得很清楚，没有把日报误判成台账的读法。
