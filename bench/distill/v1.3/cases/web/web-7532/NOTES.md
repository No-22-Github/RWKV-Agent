## Reference solution
1. 搜索岫山 G-3112，命中游客帖与官方错误码速查页。
2. 打开官方速查页正文，逐码核对。
3. G-3112 行：儿童票未绑定监护人，补选监护人后重刷，作答。

## Why the answer is unique
官方速查页按码逐行列出：G-3112 是「儿童票未绑定监护人」；G-3115 是「身份证号校验失败」，属于另一个码，帖子内容与官方页对 G-3115 的描述一致，恰好证明两码不同；G-3110 二维码过期、G-3118 闸门未复位也与题面不符。答案唯一。
