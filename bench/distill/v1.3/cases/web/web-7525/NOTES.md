## Traps
- 无陷阱（L0 基题）。同页「离线缓存只保留最近 200 条」是相邻数字，注意题面问的是列表保存上限。

## Reference solution
1. 搜索枕流浏览器 稍后再读，命中帮助中心功能页。
2. 打开正文：「最多可保存 5000 条内容」，作答 5000。

## Why the answer is unique
页面里「稍后再读」列表的上限只有「最多可保存 5000 条」一处；200 是离线缓存条数，收藏夹明确不受上限限制，都不对应题面问法。答案唯一。

## 正确答案
5000
