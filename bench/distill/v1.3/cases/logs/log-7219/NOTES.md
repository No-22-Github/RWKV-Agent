## Traps
- TR-TZ: patrol-1 按 UTC 记时。它有 8 条冷机启停失败 ERROR 的时间戳还写在 08-29（北京时间已是 08-30 凌晨），只按时间戳日期统计会漏掉它们；另有 9 条时间戳写在 08-30 下午到夜里、北京时间已是 08-31，只按时间戳日期统计会多算。换算到北京时间后，当天（08-30）的冷机启停失败 ERROR 共 34 条。

## Reference solution
1. 读 README.md：行格式与 patrol-1 的 UTC 约定。
2. 检索「冷机启停失败」，在命中处附近的行段里逐条核对级别与写入方。
3. patrol-1 的时间戳加 8 小时换算到北京时间，其余写入方按原时间戳取日期。
4. 只保留北京日期为 08-30 的 ERROR 行，共 34 条。

## Why the answer is unique
README 写明只有 patrol-1 按 UTC 记时，换算规则唯一；级别与描述开头限定了计入的行。前一天晚上与次日凌晨的 patrol 行分别落在窗口两侧。答案是 34。
