## Traps
- TR-WEBSTALE: 经销商门户的对账单写着应付余额 4210 元，但数据截至 2026-07-31，是滞后数据；以门户为准会答 4210。
- TR-DECOY: 台账里华达商贸还有一行 7 月货款（1055 元），不按月份筛会把 7 月也算进去，得 5490。
## Reference solution
1. 打开 销售台账.csv，README 写明对账以台账为准。
2. 取客户为华达商贸、日期在 2026-08 的三行：1280、940、2215。
3. 求和 1280+940+2215，回答 4435。
## Why the answer is unique
README 写明对账以台账为准且门户数据滞后，门户的 4210 是 7 月末口径、不能用于 8 月对账；台账按客户和月份筛后只剩三行 8 月华达记录，7 月那行不满足「8 月的货款」，因此 4435 唯一。
