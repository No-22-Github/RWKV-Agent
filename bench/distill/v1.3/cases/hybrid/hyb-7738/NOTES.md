# hyb-7738 NOTES

- 会话形状：派活后道谢再追问（第 1 轮净收入任务，第 2 轮道谢 + 追问最大单笔退款）。
- 语言：中文。两轮都按数值判：第 1 轮答案 15060.00，第 2 轮答案 620.00。

## Traps

- TR-SIGN: finance/march_cashflow.csv 里退款行按正数记账（README 写明，类别列区分收入与退款）。不注意会得到：把全部行加总得 17540（收入 16300 + 退款 1240），trap_decoys 记 17540。

## Reference solution

1. 第 1 轮：读取 finance/march_cashflow.csv，README 写明退款按正数记、靠类别列区分（第 1 次工具调用）。
2. 收入行求和 16300.00，退款行求和 1240.00，净收入 = 16300.00 - 1240.00 = 15060.00。
3. 第 2 轮：取类别为退款的三行中的最大值：620.00（第 2 次工具调用，重读同一文件；ref_calls = 2）。

## Why the answer is unique

17540 把退款也当成了收入，但 README 写明退款按正数记账，净收入必须把退款从收入里扣掉，17540 是毛流水而非净额；16300 是只算收入的毛收入，也不是「净」。15060 是唯一同时用上两个类别的结果。620.00 是退款行里唯一的最大值，320.00 与 300.00 都比它小；把 620.00 之外的任何数字（如收入最大行 6800.00）当退款都与类别列不符。

## Five alternative phrasings

1. 帮我算下 3 月的净收入，文件在 finance/march_cashflow.csv，只要数字。
2. finance/march_cashflow.csv 里 3 月净赚多少？
3. 把 3 月流水按收入和退款算出净额，报个数字就行。
4. 云栖瑜伽 3 月的净收入是多少？流水在 finance/march_cashflow.csv。
5. 统计 3 月净收入（扣掉退款），只回数字。
