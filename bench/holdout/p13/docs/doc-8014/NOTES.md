## Traps
- TR-DECOY: 条款总览里最显眼的相近条款是第 3 条 餐费补助，但该条写明「仅限出差本人，不适用于陪同或招待他人」。直接套第 3 条回答「能报」是错的：制度里根本没有招待费/宴请条款，应如实说明缺失，并指出第 3 条为何不适用。

## Reference solution
1. 读 报销制度.md 的条款总览：6 条里没有招待费、宴请、酒水相关条款。
2. 逐条核对正文确认；最接近的是第 3 条 餐费补助，但仅限出差本人。
3. 回答：制度没有对应条款，招待费不能按这份制度报；第 3 条餐费补助不适用，需走业务费审批或由行政补制度。

## Why the answer is unique
条款总览与正文都只覆盖交通、住宿、餐补、审批、发票、时限六件事，招待费不在其中，这是夹具事实，没有第二种读法；把第 3 条当依据的读法与该条「不适用于招待他人」的原文冲突。合格的回答必须说明没有对应条款并点名相近条款为何不适用。
