# 题库总表

> 本文件由 `rwkv-lab exam build` 根据 `bench/exam/*.json` 自动生成，**不要手改**。
> 改题之后重新运行 `go run ./cmd/rwkv-lab exam build`；`exam build --check` 和 `exam lint` 会挡住没重建的改动。

## 怎么跑

```bash
./local/bin/rwkv-cli agent-eval --profile g1k --strict-spec --cases bench/exam/quick.json --harness app ...
```

- `--cases` 可以直接指向下面任意一个 JSON 清单；题目文件留在各自原来的目录，清单只记路径和内容哈希。
- 清单哈希相同的两次跑分才能直接比。题目改过、清单重建过，哈希就会变。

## 名词

每道题有一个**任务类型**（用户想让 App 做什么）和零到多个**难点**（这道题难在哪）。

| 任务类型 | 意思 |
|---|---|
| `answer-direct` | 直接回答（不该调工具 / 该先反问） |
| `find-read` | 查找与阅读本地文件 |
| `compute` | 统计与计算 |
| `write` | 改文件与写产物 |
| `external` | 外部信息（上网、天气） |

| 难点 | 意思 |
|---|---|
| `multi-source` | 多个来源拼答案 |
| `check` | 核对与守约束（版本冲突、数据里的指令、只读） |
| `recovery` | 出错恢复（路径不对、链接失效、工具报错） |
| `long-input` | 长输入（大文件、截断、分页） |
| `follow-up` | 用户追问（不止一条用户消息） |
| `decoy` | 有相似的干扰答案 |

| 判分方式 | 意思 |
|---|---|
| `number` | 数字（允许误差） |
| `exact` | 整句精确相等 |
| `contains` | 回答里包含正确值 |
| `abstain` | 应说明查不到 |
| `no-call` | 不调工具直接答 |
| `file` | 只看文件最后的样子 |
